手机 APP 工作流程
1. 安装 APK，首次打开填写「接入码」（本页配置列表可见）。
2. APP 从私有仓库读取配置并校验：配置已启用 + 该设备码已绑定 + 未超过 3 台 → 允许使用。
3. 本页停用配置或解绑设备后，手机端下一次启动即被拒绝。
4. 配置内容、设备绑定、操作记录全部保存在你的 GitHub 私有仓库，仅你可见。
